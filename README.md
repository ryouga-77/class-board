# 学級掲示板 OS v3.9.4 (Class Board OS)

中学校の学級運営をデジタルでスマートにする、HTML/Tailwind CSSベースの掲示板生成システムです。
村田町のリアルタイム気象データ取得機能に加え、プロフェッショナルな制作フローをサポートするチェックリスト機能を搭載しています。

## 主な機能

- **動的気象データ取得**: 気象庁APIから宮城県村田町の天気・気温を自動取得。
- **インテリジェント・デコレーター**: 
    - `==テキスト==` でマーカー（蛍光ペン）
    - `"テキスト"` で太字強調
    - 半角・全角の混在にも対応した柔軟な判定アルゴリズム。
- **Publishing Workflow**: 情報収集からAIトーンチェック、最終校正までを管理するチェックリストを搭載。
- **背景自動伸縮**: 連絡事項や宿題の量が増えても、キャンバスが自動で拡張し情報を逃しません。
- **高画質画像書き出し**: 1080px（高画質設定）のPNG画像として保存し、LINE等ですぐに共有可能。

##  使用技術

- **Frontend**: HTML5, JavaScript (Vanilla JS)
- **Styling**: Tailwind CSS (CDN)
- **Icons**: Lucide Icons
- **Library**: html-to-image v1.11.11
- **Fonts**: BIZ UDPGothic (UDフォント), Inter

## 使い方

1. `index.html` をブラウザで開きます。
2. **Workflowパネル**: 上から順にステップを確認し、作業の抜け漏れを防ぎます。
3. **エディタパネル**: 「天気」「時間割」「事務連絡」などの各項目を入力。
    - マーカーを引きたい時は `==重要==` のように入力します。
4. **AI Tone Check**: 週末や連休の投稿前には専用ボタンでトーン確認を推奨。
5. **保存**: 「画像を保存して送信」ボタンで、日付入りのファイル名で画像を出力します。

##  デザインコンセプト

「毎日のブリーフィング（Daily Briefing）」をテーマに、黒と白のコントラストを活かしたモダンなインターフェースを採用。
UD（ユニバーサルデザイン）フォントを採用することで、誰にとっても読みやすく、かつ「見るのが楽しくなる」プロフェッショナルなデザインを目指しています。
