# 学級掲示板 OS v3.5 (Class Board OS)

中学校の学級運営をデジタルでスマートにする、HTML/Tailwind CSSベースの掲示板生成システムです。
村田町のリアルタイム気象データ取得機能や、内容量に応じた背景自動伸縮機能を搭載しています。

##  主な機能

- **動的気象データ取得**: 気象庁のAPIから宮城県村田町の天気・気温・警報情報を自動取得し表示します。
- **次回の時間割表示**: 「TimeSchedule」セクションを独立させ、翌日の準備を明確化。
- **背景自動伸縮 (v3.4以降)**: 連絡事項や宿題の量が増えても、背景の白い領域が自動で下に伸び、情報が欠けるのを防ぎます。
- **レスポンシブ・エディタ**: PCのブラウザから直感的に入力し、プレビューをリアルタイムで確認可能。
- **高画質画像書き出し**: 入力した内容をPNG画像として保存し、LINEグループ等で即座に共有できます。

##  使用技術

- **Frontend**: HTML5, JavaScript (Vanilla JS)
- **Styling**: Tailwind CSS (CDN)
- **Icons**: Lucide Icons
- **Image Generation**: html-to-image
- **Fonts**: Noto Sans JP, Inter

##  使い方

1. `index.html` をブラウザで開きます。
2. 左側のエディタパネルで「天気」「時間割」「事務連絡」などの各項目を入力します。
3. 「村田町の情報を更新」ボタンを押すと、最新の気象データが反映されます。
4. 右側のプレビューでデザインを確認します。
5. 「画像を保存する」ボタンをクリックして、共有用の画像を出力します。

## 開発ロードマップ (バージョン履歴)

- **v3.5**: 「次回の時間割」タイトルセクションの追加。

- **v3.3**: 全体的なフォントウェイトの調整（太字から洗練された中太字へ）。

##  デザインコンセプト

「毎日のブリーフィング（Daily Briefing）」をテーマに、黒と白のコントラストを活かしたモダンでプロフェッショナルなインターフェースを採用。学校のプリントのような無機質さを排除し、見るのが楽しくなるデザインを目指しています。
